# Interviews

Transcripts from `/project:interview`, named `YYYY-MM-DD-<slug>.md` after the topic (often a new entity's slug). Each is written question by question and answer by answer as the interview runs, then turned into the structured pages — `requirements.md`, `architecture.md`, `entities/`, `decisions/`, `todos.md` — so an interview normally needs no summary page (`/project:wiki <file>` makes one if you want a digest).

**Never edit a prior answer.** A correction is a new interview on the same topic; later transcripts win, and `/project:wiki` flags any contradiction that survives.
